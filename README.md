# 🎮 Guess the Number Game

A simple and interactive Guess the Number Game developed using HTML, CSS, and JavaScript. Players can enter their details and try to guess the randomly generated number.

## 🚀 Features

- 👤 User login page
- 🎲 Random number generation
- 🔢 Enter your guessed number
- ⬆️ Display hint if the guess is too high
- ⬇️ Display hint if the guess is too low
- 🏆 Show winning message
- 🔄 Restart the game
- 📊 Track number of attempts
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter your details and start playing!
