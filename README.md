# 🎮 Number Game

A simple and interactive Number Game developed using HTML, CSS, and JavaScript.

## 🚀 Features

- Simple and user-friendly interface
- Interactive number guessing game
- Easy-to-use login page
- Instant game results
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Number-Game/
│
├── index.html
├── basic.css
├── script.js
└── README.md
```

## ⚙️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing the game!
